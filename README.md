# Smart Home IoT System

Embedded IoT system designed with modular architecture, automated testing and CI integration.

## 🏗 Architecture

- Firmware modules (WiFi, Uplink, Display)
- Modular communication via JSON DTO
- CI pipeline via GitHub Actions
- Unit tests integrated in workflow

## 🔧 Tech Stack

- C / C++
- PlatformIO
- Embedded Systems
- GitHub Actions CI

## 🚀 Key Features

- WiFi connectivity management
- JSON-based communication layer
- Display control module
- Automated unit testing

## 📈 Engineering Focus

- Modular firmware design
- Separation of concerns
- Continuous integration
- Hardware abstraction
